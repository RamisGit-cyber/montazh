# Монтаж рилсов — плагин для Claude Code

Агентный монтаж рилсов «говорящая голова» (вертикаль 1080×1920, Instagram Reels). Claude сам:

- расшифровывает речь и вырезает паузы, оговорки и повторы;
- ставит субтитры фразой целиком и вставки по смыслу сказанного;
- подбирает музыку (своя или из библиотеки плагина) и звуки;
- проверяет ролик критиком: лицо говорящего видно, ничего не закрывает лицо и рот, субтитры не лезут под кнопки Instagram, звук без провалов.

Повторяет монтаж образца, если вы его даёте. Ничего не публикует: готовый ролик лежит в папке `готово/`.

## Установка

Скажите своему Claude:

> Установи плагин монтажа рилсов: запусти `claude plugin marketplace add RamisGit-cyber/montazh`, потом `claude plugin install montazh@montazh` и скажи, когда закончишь.

Или вручную в терминале:

```
claude plugin marketplace add RamisGit-cyber/montazh
claude plugin install montazh@montazh
```

В Claude Desktop (вкладка Code) после установки перезапустите приложение.

## Как пользоваться

Откройте Claude в папке проекта, положите видео (можно прямо в папку) и напишите: «смонтируй рилс». Если есть образец — пришлите ссылку или файл: «смонтируй как в образце».

Нужны ffmpeg, uv и (для красивого режима «Про») Node 22+ и навыки HyperFrames — Claude проверит и поставит недостающее сам.
